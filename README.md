Smart Contact Manager – Project Description

Smart Contact Manager is a web-based application developed using Java, Spring Boot, Spring Security, MySQL, and Thymeleaf to simplify contact management. It allows users to register and log in securely, add new contacts, view contact details, update existing information, delete contacts, and search for specific contacts easily.

The application provides a user-friendly interface and stores contact information in a database. It uses authentication and authorization to ensure that users can securely manage their own contacts. This project helped me gain practical experience in Java development, database integration, CRUD operations, Spring Security, and building web applications using the Spring Boot framework.

The main goal of this project is to provide a secure, efficient, and organized solution for managing personal and professional contact information.
